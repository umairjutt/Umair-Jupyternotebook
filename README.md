# Data Science Tools and Ecosystem - coursework

An introductory IBM course exercise completed in Jupyter Notebook.

[Open the notebook](DataScienceEcosystem.ipynb)

## Topics

- Common data-science languages, libraries and tools.
- Markdown headings, lists and tables in a notebook.
- Basic Python arithmetic and minutes-to-hours conversion.

## Context

This repository preserves coursework and learning history. It is not an applied machine-learning product or a benchmark of professional data-science experience. The notebook retains the original course context and attribution.

## Run locally

Open the notebook in Jupyter Notebook or another compatible editor with a Python kernel. The arithmetic cells use no third-party Python packages.
